Projeto acadêmico

Um passeio pelos sabores locais

Este site foi desenvolvido para a Tarefa 06 da disciplina de Web Design. A proposta é praticar HTML5 semântico, CSS externo, organização visual e responsividade usando referências públicas sobre restaurantes reais.

As informações são um ponto de partida para pesquisa. O guia não representa ranking, publicidade ou avaliação dos estabelecimentos.
