Projeto acadêmico

Um passeio pelos sabores locais

Este site foi desenvolvido para a Tarefa 06 da disciplina de Web Design. A proposta é praticar HTML5 semântico, CSS externo, organização visual e responsividade usando referências públicas sobre restaurantes reais.

As informações são um ponto de partida para pesquisa. O guia não representa ranking, publicidade ou avaliação dos estabelecimentos.

Conteúdo consultado em setembro de 2026.

Voltar às sugestões

Como ler este guia

Informação clara para uma escolha tranquila.

As sugestões desta página foram selecionadas a partir de páginas públicas consultadas durante a pesquisa da atividade.

O conteúdo resume categorias e localização geral sem substituir o cardápio, o horário ou os canais oficiais dos restaurantes.

Use os links dos cartões para continuar a pesquisa antes de sair.
