      COMEÇAR

      Um caminho simples para construir clareza.

      O FinDash foi pensado para registrar acontecimentos financeiros reais e transformá-los em uma visão organizada. Comece por um lançamento pequeno; a consistência vale mais do que tentar reconstruir toda a vida financeira de uma vez.

      1. Registre uma entrada.Inclua salário, trabalho pontual, reembolso ou qualquer valor que entrou.
      2. Registre uma saída.Anote a despesa com uma descrição que faça sentido para você.
      3. Leia o resumo.Compare receitas, despesas, saldo e taxa de economia.
      4. Planeje o mês.Defina limites para categorias onde você deseja ter mais atenção.
      Dica prática

      Faça os lançamentos no mesmo dia em que acontecem. Assim, os indicadores e o gráfico representam melhor sua rotina.

      LANÇAMENTOS

      Como cadastrar receitas e despesas.

      Na área de lançamentos, escolha o tipo, informe uma descrição breve, valor, categoria e data. O formulário confirma se a informação está completa antes de salvar.

      Tipo

      Use Receita para valores que entram e Despesa para valores que saem. Essa escolha influencia todos os cálculos.

      Descrição

      Prefira termos específicos, como “Mercado do bairro” ou “Freelance de setembro”, para facilitar a pesquisa posterior.

      Valor

      Você pode digitar 12,50, 12.50 ou 1.234,56. O FinDash armazena o resultado em centavos.

      Data

      A data precisa existir no calendário. Ela define o período dos orçamentos e do gráfico mensal.

      Editar ou excluir

      Em cada item da lista, use o botão com lápis para trazer seus dados ao formulário e salvar uma atualização. O botão de exclusão sempre abre uma confirmação; cancelar mantém o lançamento intacto.

      Encontrar um lançamento

      A pesquisa procura tanto na descrição quanto na categoria. Ela ignora maiúsculas, minúsculas e acentos: pesquisar por “alimentacao” encontra “Alimentação”. Combine-a com tipo, categoria e ordenação para chegar ao resultado desejado.

      INDICADORES

      Como interpretar a visão geral.

      Os quatro cartões de resumo consideram todos os lançamentos cadastrados no navegador, e não apenas o mês corrente. Isso deixa claro o período apresentado.

      Receitas
      Soma de todos os lançamentos classificados como receita.
      Despesas
      Soma de todos os lançamentos classificados como despesa.
      Saldo
      Resultado de receitas menos despesas. Um saldo negativo merece atenção.
      Lançamentos
      Quantidade total de registros guardados no FinDash.
      Taxa de economia
      Calculada como (receitas − despesas) ÷ receitas × 100. Sem receita, ela não é exibida.
      Leitura responsável

      Um único indicador não substitui a análise do contexto. Use o histórico, os filtros e seu planejamento pessoal antes de tomar decisões financeiras importantes.

      ORÇAMENTOS

      Planejamento por categoria, todo mês.

      Um orçamento é um limite mensal recorrente. Ao definir, por exemplo, R$ 900,00 para Alimentação, o FinDash compara esse valor com as despesas daquela categoria no mês de referência atual.

      1

      Defina um limite realista. Use sua rotina recente como referência e reserve margem para oscilações.

      2

      Acompanhe a barra. A cor muda quando o consumo se aproxima ou ultrapassa o limite.

      3

      Ajuste quando necessário. Use o lápis para revisar o limite; use a exclusão para remover uma categoria do planejamento.

      Despesas de meses diferentes não são misturadas. Ao virar o mês, os limites continuam disponíveis, mas o valor usado passa a considerar apenas as novas despesas daquele período.

      GRÁFICO

      O que o gráfico mostra.

      O gráfico de barras usa Canvas e agrupa exclusivamente as despesas do mês atual por categoria. Cada cor representa uma categoria e a altura de cada barra mostra seu valor relativo.

      • Registre uma despesa com data no mês atual para ver uma barra.
      • Edite ou exclua uma despesa para redesenhar automaticamente o gráfico.
      • Redimensione a tela: o desenho é recalculado para se ajustar ao espaço disponível.
      • Use a legenda abaixo do gráfico para identificar as categorias.

      Se não houver despesas no mês atual, o FinDash exibe uma mensagem em vez de um gráfico vazio.

      DADOS E PRIVACIDADE

      Onde ficam suas informações.

      O FinDash não possui conta, login, servidor ou integração bancária. Lançamentos, orçamentos e preferência de tema ficam no localStorage do navegador que você está usando.

      O que é salvo

      Descrição, tipo, categoria, data e valor em centavos de cada lançamento; categoria e limite em centavos de cada orçamento; preferência de tema.

      O que não é enviado

      O site não transmite dados financeiros para um servidor, não usa banco remoto e não acessa sua conta bancária.

      Exportação

      O botão Exportar dados cria um arquivo JSON local com metadados, transações e orçamentos. A exportação não envia nada.

      Cuidados

      Limpar dados do navegador pode apagar o armazenamento local. Exporte uma cópia se quiser preservar informações importantes.

      Dados demonstrativos

      O botão Restaurar exemplos carrega lançamentos e orçamentos fictícios para exploração da interface. Ele pede confirmação porque substitui os registros atuais.

      PERGUNTAS FREQUENTES

      Dúvidas rápidas.

      O FinDash funciona sem internet?

      Sim. Como a aplicação usa recursos nativos do navegador e armazenamento local, os dados já salvos continuam acessíveis sem conexão.

      Posso cadastrar valores negativos?

      Não. O tipo do lançamento informa se é receita ou despesa; o campo de valor aceita apenas números positivos.

      Por que meu orçamento está zerado?

      O uso do orçamento só conta despesas da mesma categoria cujo mês e ano sejam iguais aos do mês atual.

      Por que a taxa de economia mostra um traço?

      Ela depende de receitas registradas. Sem uma receita, não existe base para calcular a proporção.

      Posso importar um arquivo JSON?

      Não nesta versão. O FinDash oferece somente exportação para manter o fluxo simples e local.

      O tema permanece depois de fechar a página?

      Sim. Sua escolha entre tema claro e escuro fica salva neste navegador.

      Como apagar todos os meus dados?

      Esta interface não tem uma limpeza global. Você pode excluir lançamentos e orçamentos individualmente ou limpar os dados do site nas configurações do navegador.

      Botões, campos, links, filtros, modais e perguntas frequentes podem ser alcançados com a tecla Tab. O foco visível indica o controle ativo.

      Leitores de tela

      O CSS respeita a preferência do sistema para reduzir animações de rolagem e transições quando ela está ativada.

      SOLUÇÃO DE DÚVIDAS

      Quando algo não parecer certo.

      “O valor não foi aceito”

      Use somente números positivos e um separador decimal. Exemplos válidos: 25, 25,50, 25.50 e 1.234,56.

      “A data não salva”

      Escolha uma data existente no campo de calendário. Datas como 31 de fevereiro são rejeitadas pela validação.

      “Não encontro um lançamento”

      Remova os filtros, limpe a pesquisa e escolha “Todos os tipos” e “Todas categorias” antes de buscar novamente.

      “O gráfico não aparece”

      Confirme se existe ao menos uma despesa datada no mês atual. Receitas e despesas de meses anteriores não entram nele.

      “Meus dados sumiram”

      O armazenamento local pode ser apagado pelas configurações do navegador, por modo privado ou por limpeza de dados. Use a exportação como cópia preventiva.

      “O tema voltou ao anterior”

      Verifique se o navegador está permitindo dados locais para esta página. Sem armazenamento, a preferência não pode ser mantida.

      GLOSSÁRIO

      Termos usados no painel.

      Esta referência curta ajuda a manter a leitura dos recursos consistente.

      Receita
      Valor que entra no seu fluxo financeiro, como salário, venda, reembolso ou trabalho pontual.
      Despesa
      Valor que sai do seu fluxo financeiro, como mercado, transporte, mensalidade ou lazer.
      Categoria
      Grupo usado para organizar lançamentos semelhantes e permitir filtros, orçamento e gráfico.
      Saldo
      Diferença entre todas as receitas e todas as despesas que foram cadastradas.
      Orçamento
      Limite mensal recorrente para uma categoria específica; não é um lançamento financeiro.
      Mês de referência
      Mês atual do dispositivo, usado no cálculo de gastos de orçamento e no gráfico de despesas.
      Taxa de economia
      Percentual de receita restante após subtrair as despesas, podendo ser negativo.
      Centavos
      Unidade inteira usada internamente para guardar valores monetários sem imprecisão de ponto flutuante.
      Armazenamento local
      Espaço do navegador que guarda dados nesta máquina, sem transmissão a um banco de dados remoto.
      JSON
      Formato de texto estruturado usado pelo arquivo de exportação para organizar dados e metadados.

      Se algum termo financeiro for novo para você, encare-o como uma forma de observar padrões, não como uma regra rígida. O planejamento mais útil é o que se adapta à sua realidade.

      BOAS PRÁTICAS

      Pequenos hábitos que ajudam na organização.

      O FinDash oferece dados; as escolhas continuam sendo suas. Estes princípios orientam um uso equilibrado da aplicação.

      Registre sem julgamento

      Um histórico confiável inclui gastos confortáveis e gastos difíceis. Registrar é observar, não punir.

      Compare períodos equivalentes

      Ao analisar um orçamento, compare despesas do mesmo mês de referência e considere compromissos sazonais.

      Use categorias coerentes

      Manter categorias semelhantes para gastos semelhantes melhora o valor do gráfico e dos filtros.

      Revise antes de concluir

      Uma edição simples pode corrigir tipo, valor ou data sem afetar os demais registros.

      Importante

      O FinDash é uma ferramenta educacional de acompanhamento pessoal e não oferece aconselhamento financeiro, bancário, tributário ou de investimento.
